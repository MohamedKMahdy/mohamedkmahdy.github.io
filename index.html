Revit 2023 to 2027 · batch

Bimnox

Runs model checks and exports on dozens of Revit models at once, on a schedule, with nobody sitting at the computer.

One codebase covers every Revit version from 2023 to 2027 and sends each model to an installed Revit that can open it. German and English interface, and it installs per user without admin rights.

Speckle · local AI

ARVENT

Answers questions about a 3D building model in plain language, right in the model's comment threads. It runs on a local AI model, so the data stays on the machine.

What I learned in 2023 still holds: the AI was never the hard part. Getting clean, structured data out of the design tools is.

Revit + web

Raumbuch

Builds a room book, every room and everything in it, straight from the building model. A Revit add-in, plus a web app that also opens IFC files.

I didn't want it tied to one vendor. IFC files open without any login, are read in the browser and never leave your machine, and you can load several at once as one model.

About

A bit about me

I trained as an architectural engineer, and the drawings were never the part that hooked me. It was the logic behind them. The interesting problems in construction turned out to be data problems: project information stuck in disconnected tools and manual routines. I build the systems that connect it.

That has meant Revit and Navisworks plugins, model-health and clash dashboards, and automation that runs on its own, in Cairo, Dubai and now Munich. Along the way I did 18 freelance client projects, 895 billable hours with a 5.0 average rating, and doubled my rate.

In 2024 I left a good full-time job to do the ITBE master's at TUM, and I don't regret it for a second. It added the half I was missing: GIS, spatial data mining, photogrammetry and remote sensing, next to semantic modelling and software engineering. BIM, GIS and AI are converging, and not many people work across all three.

How I build

  • People stay in controlEvery action is one undo step. There's a dry run before anything changes. When AI suggests something, a person signs off.
  • Boring is a featureThe best tools run overnight, try again when the network drops, and never leave a half-finished result that looks finished.
  • Data stays where it belongsAI models that run locally, IFC files read in the browser instead of uploaded, and no passwords or keys baked into a program.
  • Open where it countsIFC, IDS and BCF wherever they fit, so nobody gets locked into one vendor.
