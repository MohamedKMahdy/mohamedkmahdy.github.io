ACC · backups

LARBACC

Cloud-hosted does not mean backed up.

  • C#
  • .NET 8
  • WPF
  • Autodesk Platform Services (PKCE)
  • Data Management API

The problem

Projects in Autodesk Construction Cloud feel safe because they live in the cloud. A deleted folder or an ended subscription can still take years of work with it.

What it does

LARBACC (Local, Automatic, Rotating Backups of Autodesk Construction Cloud) keeps dated local copies of ACC and BIM 360 projects. Pick projects and folders, a destination and a weekly time; LARBACC downloads the latest version of every document and keeps the last few backups. The interface is in German and English.

Incremental by hard links. A document unchanged since the previous backup is linked instead of downloaded again, so later runs are fast and five kept backups do not take five times the space. A run only becomes a backup once its manifest is written, so a crash or power cut never leaves a half-finished folder that looks complete.

Sign-in uses PKCE, so no client secret ships with the program. A scheduled backup missed while LARBACC was closed runs at the next start, and a failed one is retried after 15 minutes, 1 hour and 4 hours.

Features

  • Pick ACC and BIM 360 projects, folders and a destination; the latest version of every document is saved under its ACC name
  • One dated folder per project and run, with a report and a manifest of every file and its ACC version
  • Unchanged documents are hard-linked from the previous backup instead of downloaded again
  • Keeps the last backups per project (5 by default); never deletes anything after a run with failures
  • A run only becomes a backup once its manifest is written; failed and cancelled runs are kept and labelled
  • Include or exclude any folder; new folders follow their parent
  • Weekly schedule on any days and time, running from the notification area and optionally with Windows
  • Missed backups are made up at the next start; failed ones are retried after 15 minutes, 1 hour and 4 hours
  • Sign-in with PKCE, no client secret shipped; an optional secret is stored encrypted for the Windows user
  • Parallel downloads (1 to 8), a test run that downloads nothing, daily logs
  • German and English interface
HighlightOpen-source roots: LARBACC began as a WPF front end for Stewart Celani's MIT-licensed autodesk-construction-cloud-backup, and keeps that history and credit.
