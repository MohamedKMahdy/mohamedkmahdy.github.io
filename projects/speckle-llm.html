I put an LLM on BIM data before it was a category

Speckle · LLM · natural-language model queries

In 2023 I connected Speckle to a large language model so project teams could ask questions about a 3D model in plain language. At the time there was no name for this.

The lesson has shaped everything since: the model was never the hard part. The hard part is getting clean, queryable, structured data out of the authoring tools, which is what most of my work has been about ever since.

Later built a custom Speckle–Revit connector for a separate client, extending open interoperability between the two platforms.
