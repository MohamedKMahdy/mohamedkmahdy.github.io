Revit add-in

Cloud Revisions

Where the cloud APIs stop, an add-in starts.

  • C#
  • Revit API 2023 to 2027
  • .NET Framework 4.8 / .NET 8 / .NET 10
  • dependency-free Excel and HTML

The problem

Keeping track of which revision clouds sit on which sheets, and under which revision, usually means clicking through the sheets one by one.

What it does

Revision clouds are annotation elements. The APS AEC Data Model API does not expose them and the Model Derivative API only inconsistently, so the only complete source is the Revit API itself.

The add-in lists every revision cloud in the active model with its view, the sheet it appears on and the full revision data (sequence, number, date, description, issue status, issued by and to), then exports a formatted Excel workbook or a self-contained HTML dashboard with Power BI style filtering. Everything sits in one docked panel on its own ribbon tab, in German or English.

Version 2.0 has its own name, logo and ribbon tab.

Features

  • Lists every revision cloud in the active model
  • Per cloud: id, view and view type, the sheet it appears on, revision sequence, number, date, description, issue status, issued by and to, comment and mark
  • Filters for revision, clouds on sheets only and issued revisions only
  • Formatted Excel workbook with frozen header and filters
  • Offline HTML dashboard with KPI tiles, filter chips, linked charts and a searchable, sortable table
  • Neither export needs Excel, a CDN or internet access
  • One docked panel on its own ribbon tab, German or English, with an explanation for every option
  • Revit 2023 to 2027, no dependencies
HighlightNeither export needs Excel, a CDN or internet access: both files are written by the add-in itself, so they work behind a corporate proxy.
