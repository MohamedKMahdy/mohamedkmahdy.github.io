Revit · interior finishes

RIFADEX

Finish walls, floors, skirting and ceilings that follow the rooms.

  • C#
  • Revit API 2024 to 2027
  • .NET Framework 4.8 / .NET 8 / .NET 10
  • WPF
  • extensible storage
  • no third-party libraries

The problem

Modelling interior finishes by hand, room by room, is slow, and every design change leaves finishes that no longer fit the room.

What it does

Lengths are shown and typed in the project's units. Pick a wall, floor, base and ceiling finish for each room, from this model or from a linked architect's model, singly or for many rooms at once. RIFADEX then draws one finish wall per run of room boundary, a floor per room with openings for columns and shafts, skirting that stops at doors, and a ceiling at the room height. Doors and windows of the walls behind are cut through the finish walls.

Plan, preview, apply. Every change is shown before anything is drawn, and running it again updates existing finishes in place, keeping their element ids: a new code changes the type, a room that changed shape is redrawn, openings follow moved doors, and a type you changed by hand is kept, so a feature wall survives. The linked model is never touched.

Finish types and materials are managed in a table or round-tripped through Excel, with new rows creating new types and an optional naming convention. One XML settings file holds the company standard, so any template works and nothing has to be added to a project first.

RIFADEX (Revit Interior Finishes: Assignment, Drawing and Excel eXchange) is one company-neutral bundle that rebuilds my earlier in-house finishes tools, without any office-specific parameter.

Features

  • Choose wall, floor, base (skirting) and ceiling finishes per room, from this model or a linked model
  • Set finishes for many rooms at once, filter by level, search or any room parameter, group rooms by name
  • Draws finish walls against the room boundary, a floor per room with openings, skirting that stops at doors, and a ceiling at the room height
  • Door and window openings are cut through the finish walls from the walls behind, linked or not
  • Plan, preview, apply: every change is shown before anything is drawn
  • Running it again updates existing finishes in place, keeps hand edits, and does not redraw skirting you deleted
  • Height and floor offset can be overridden per room; lengths in the project's units
  • Remove drawn finishes per room and surface; a count of what was drawn per room
  • Finish types and materials in a table or round-tripped through Excel; new rows create new types
  • Optional naming convention built from tokens
  • One XML settings file holds the company standard and can live on a server; any template works
  • No shared parameters and no third-party DLLs; Revit 2024 to 2027 from one codebase
HighlightTested inside Revit end to end: drawing, redrawing, hand edits, door cuts, a moved and rotated link and an Excel round trip, from one codebase for Revit 2024 to 2027 with no third-party DLLs.
