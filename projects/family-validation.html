Family Validation

Clean families in, clean library out.

  • C#
  • Revit API 2023 to 2027
  • WPF
  • .NET Framework 4.8 / .NET 8 / .NET 10
  • no third-party libraries
In plain words

Revit models are built from reusable components called families, such as a door, a chair or a light fitting. Companies keep libraries of hundreds of them, and one badly made family can slow down every project that uses it. Family Validation checks a whole folder of families against the company's rules, fixes what it safely can, and writes a report.

ResultNo third-party libraries. It's .NET and the Revit API only, built separately for the .NET version each Revit release ships with.

The problem

One badly built family, say one with a CAD drawing imported inside it or in the wrong category, slows down every project that loads it. Nobody checks hundreds of them by hand.

What it does

A small launcher runs Revit in the background, opens every family in a folder and checks it: the file name against the naming rules (fixing the category prefix when that's safe), imported CAD inside the family (removed, linked CAD kept), whether the name matches the category, required parameters, file size limits, and optionally a classification code like DIN 276 or Uniclass. What comes out is ready for the company library or the Autodesk Content Catalog.

Safe by design. The original is copied aside before anything happens, and if that copy fails the family is skipped. Cleaned copies go into their own folder, originals are never changed, and a dry run writes the full report without touching a file.

The rules live in a visual editor, so the people who own the standard can maintain it without writing code. Name patterns are built from blocks, and the editor won't save a rule set the check would reject.

Features

  • Checks a whole folder of Revit families without the user opening Revit: a launcher runs a hidden Revit
  • File name against the naming convention, with a safe automatic fix of the category prefix
  • Removes imported CAD drawings, keeps linked CAD files, and can also check families nested inside others
  • Checks that each family's category matches its name
  • Required family parameters: present, of the right kind, and optionally filled in
  • File size warning and error limits
  • Optional classification code check against DIN 276, Uniclass or your own pattern
  • Originals are copied aside before anything else; cleaned copies go to their own folder; originals are never changed
  • Dry run that writes the full report without changing a file
  • Excel report sorted worst first, plus a log
  • Visual rules editor: name patterns from blocks, refuses rules that would fail, keeps backups, and imports rule sets from colleagues
  • Revit 2023 to 2027, German and English, no third-party libraries
