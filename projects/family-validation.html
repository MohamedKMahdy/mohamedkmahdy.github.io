Family Validation

Clean families in, clean catalog out.

  • C#
  • Revit API 2023 to 2027
  • WPF
  • .NET Framework 4.8 / .NET 8 / .NET 10
  • no third-party libraries

The problem

One badly built family, with an embedded CAD import or the wrong category, slows down every project that loads it. Checking hundreds of them by hand does not happen.

What it does

A launcher window drives a hidden Revit that opens every family in a folder and checks it: the naming convention (auto-correcting the category prefix when that is unambiguous), embedded CAD imports (removed, while linked CAD is kept), name against category, required parameters, file size limits, and an optional classification code such as DIN 276 or Uniclass.

Safe by construction. The original is copied aside before anything else, and a family whose copy fails is skipped, never touched. Cleaned copies go to their own folder, sources are never changed in place, and a dry run writes the full report without changing a file.

A visual rules editor lets non-developers maintain the standard: categories and name patterns are built from blocks instead of regular expressions, and the editor refuses to save a ruleset the run would reject.

Features

  • Checks a whole folder of Revit families without the user opening Revit: a launcher drives a hidden Revit
  • File name against the naming convention, with a safe auto-correction of the category prefix
  • Removes embedded CAD imports, keeps linked CAD, and can scan nested families for CAD
  • Checks that each family's category matches its name
  • Required family parameters: present, right binding and storage type, optionally not empty
  • File size warning and error limits
  • Optional classification code check against DIN 276, Uniclass or a custom pattern
  • Originals are copied aside before anything else; cleaned copies go to their own folder; sources are never changed
  • Dry run that writes the full report without changing a file
  • Excel report sorted worst first, plus a log
  • Visual rules editor: name patterns from blocks, refuses rulesets that would fail, keeps backups, imports rulesets from colleagues
  • Revit 2023 to 2027, German and English, no third-party libraries
HighlightZero third-party dependencies: everything is .NET plus the Revit API, with each worker built for the runtime its Revit version ships.
