Revit Automation Suite

Small tools for the jobs nobody wants to do by hand.

  • C#
  • Revit API
  • WPF
  • Excel interop

The problem

Small, repetitive Revit tasks (worksets, joins, moving types between projects, purging before issue) add up to hours of engineering time every week.

What it does

A suite of enterprise Revit add-ins built for architecture and engineering teams, covering model management, worksets, element joins and bulk file operations. Each one replaced a manual process that consumed engineering hours every week.

The quantity and finishes tools from the same years have since grown into products of their own, Qubecta and RIFADEX, and are shown there. All demos below are recorded against a generic sample model.

Features

  • Revit-Transmitter: detaches models with worksets kept or discarded, purges unused elements and prepares issue-ready files
  • Worksets Manager: creates standard worksets from Excel or by classification and assigns every element to the right one
  • Auto Joiner: joins and unjoins every intersecting element of selected categories in one pass
  • Transfer Types: transfers types and families between many projects selected from a folder tree
