Rimacos

Rules, not cells.

  • Python
  • IfcOpenShell / IfcClash
  • IDS 1.0
  • BCF
  • Navisworks XML
  • openpyxl
  • pytest

The problem

A clash matrix grows with the square of the number of clash groups. Maintaining thousands of cells by hand, and turning them into thousands of separate clash tests, does not scale.

What it does

Rimacos (Rule-based Interference Matrices And Clash tests on Open Standards) turns a short list of rules into a complete clash detection matrix and the files to run it: Navisworks search sets and Clash Detective tests, IfcClash sets with BCF output, a buildingSMART IDS file that checks the models carry what the clash groups select on, and an Excel matrix and HTML report for the BIM execution plan.

A rule says how two references are tested against each other (everything, a discipline, a tag or a single group), and the most specific rule wins. A local browser editor handles the matrix, groups and rules.

Clash groups select by IFC class and predefined type, property filters and classification codes, and models are found by their ISO 19650 container name, so the whole matrix also runs on open tooling.

Features

  • Clash rules instead of matrix cells: a rule says how two references are tested, and the most specific rule wins
  • References at four levels: everything, a discipline, a tag or a single clash group
  • Test types hard, hard (conservative), clearance, duplicate and none, each with tolerance and severity
  • Group priorities decide which side is responsible for each clash pair
  • Navisworks output: search sets and Clash Detective tests as XML, ready to import
  • IfcOpenShell output: IfcClash sets that run on IFC models and report as BCF
  • buildingSMART IDS 1.0 file that checks the models carry the classes, classifications and properties the groups filter on
  • Excel matrix for the BIM execution plan, editable and importable again
  • HTML report and CSV test list, optionally with clash counts per test and discipline pair
  • Clash groups select by IFC class and predefined type, property filters, classification codes and Revit categories
  • Models are found by their ISO 19650 container name
  • Local browser editor for the matrix, groups, rules and tests; imports classic matrix workbooks
  • Merged or per-pair test granularity
HighlightA classic 133-group matrix carried 8,778 cells. Rimacos reproduces every one of them with 4 rules, and the merged output needs 79 clash tests instead of 8,778.
