Cloud · openBIM

Cloud-connected, vendor-neutral

React · FastAPI · Autodesk Platform Services · AEC Data Model API · IFC

Authenticates against APS, browses Autodesk Construction Cloud, opens a model in the APS Viewer, extracts every room and the furniture inside it, and exports a formatted German Raumbuch to Excel or PDF.

Cross-model association. Rooms living in a linked geometry node joined to furniture in the main model through baked room parameters, with deduplication, because partial linked copies share element ids.

Queries the AEC Data Model GraphQL API directly rather than scraping the Viewer's property database, which is faster and works before the model finishes loading.

Not locked to one vendor: the same extraction runs fully offline against an uploaded IFC file via IfcOpenShell.
